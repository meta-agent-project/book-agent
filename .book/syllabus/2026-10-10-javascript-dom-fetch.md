# 강의계획서: JavaScript 기초와 DOM·fetch
- 날짜: 2026-10-10
- 브리프: .book/interview/2026-10-10-javascript-dom-fetch.md

## 강의 개요
| 항목 | 내용 |
|---|---|
| 학습목표 | JavaScript 문법을 익힌다. DOM을 제어해 순수 JavaScript와 HTML만으로 fetch 통신하는 프론트엔드를 만든다. |
| 대상·선수지식 | HTML·CSS 기본 태그와 선택자를 안다. JavaScript는 처음이다. |
| 후속과정 | React |
| 강의방법 | 이론·실습 혼합(개념 → 코드 예시 → 실습). 미니프로젝트 2개, 종합 프로젝트 1개 |
| 실행 환경 | VS Code, Chrome, Node.js 22 LTS, Live Server, JSONPlaceholder |

## 가정한 것
- 강의방법이 이론·실습 혼합이라 이론·실습 중심 구성을 쓴다. 브리프 고정 조건의 프로젝트형 항목은 쓰지 않는다.
- Node.js는 22 LTS로 한다.
- VS Code, Live Server, Node.js는 이미 설치되어 있다고 보고 1장에서는 설치 확인만 한다.
- 브리프에 없는 콘솔 미니프로젝트(9장)를 문법 묶음 끝에 넣었다. 여기서 만든 데이터 함수를 14장, 20장에서 다시 쓴다.
- CSS Grid는 DOM 미니프로젝트 뒤(15장)에 둔다. 1장부터 연결해 쓴 공통 CSS를 이 장에서 풀어 설명한다.
- CSS Grid는 기본 문법만 다룬다. 반응형 카드와 grid-template-areas는 뺀다.
- React 기반으로 단축 평가(&&, ||, ??)와 옵셔널 체이닝을 더했다.
- 고차 함수는 forEach·map·filter·find만 다룬다.
- var, while, 스코프는 다루지 않는다.
- 에러 메시지를 일부러 띄워 보여 주는 내용은 넣지 않는다. 오류 처리는 fetch 실패 처리(18~20장)에서만 다룬다.
- 동적 UI는 상태 배열을 바꾸고 render 함수로 다시 그리는 방식으로 통일한다. React의 사고방식과 같다.
- JSONPlaceholder는 POST·PUT·DELETE 결과를 저장하지 않는다. 화면은 응답을 받아 불변 업데이트로 반영한다. 검색은 받아 온 목록을 filter로 거른다.
- 제외: 클래스와 프로토타입, localStorage, 모듈, Promise 직접 구현, HTML·CSS 기초(Grid 제외), jQuery·XMLHttpRequest, Node.js 백엔드, TypeScript·번들러

- 5-2 매개변수와 반환값

### 6장. 구조분해 할당과 전개 연산자
- 6-1 배열 구조분해

- 6-2 객체 구조분해와 매개변수 구조분해
  - 객체 속성을 꺼내고 함수 매개변수에서 바로 푼다. React props의 기본 형태다.
- 6-3 값과 참조
  - 객체를 대입하면 같은 대상을 가리키는 모습을 본다.
- 6-4 전개 연산자로 복사하기

- 6-5 얕은 복사와 깊은 복사

- 연습문제

  - 설정 객체를 복사해 원본을 지키며 값 바꾸기

### 7장. 배열과 불변성
- 7-1 불변성
  - 원본을 바꾸지 않고 새 값을 만드는 이유를 안다. React 상태 관리의 전제다.
- 7-2 forEach
  - 반복문 대신 배열을 돈다.
- 7-3 map
  - 배열을 같은 길이의 새 배열로 바꾼다. React 목록 렌더링의 기본이다.
- 7-4 filter
  - 조건에 맞는 것만 남긴 새 배열을 만든다.
- 7-5 find
  - 조건에 맞는 항목 하나를 찾는다.
- 7-6 push와 전개 연산자
  - push로 넣을 때와 ...으로 새 배열을 만들 때의 차이를 비교한다. 실습: 두 방식으로 할 일 추가하고 원본 비교
- 연습문제
  - 학생 목록에서 합격자 이름 배열 만들기
  - 원본을 바꾸지 않고 장바구니에 상품 추가

- 17-4 try·catch·finally
  - 실패를 잡아 사용자에게 알리고 마무리 코드를 돈다. 실습: 제공된 delay 함수로 성공·실패 처리
- 연습문제
  - 순서대로 기다리는 세 단계 작업
  - 실패하면 다시 시도하는 함수

### 18장. AJAX와 fetch
- 18-1 AJAX란
  - 새로고침 없이 데이터를 주고받는 방식을 안다.
- 18-2 HTTP 요청과 응답
  - 메서드, 주소, 헤더, 상태 코드를 읽는다. Network 탭으로 확인한다.
- 18-3 REST API와 JSON
  - 자원 중심 주소 설계와 JSON.stringify·JSON.parse를 배운다.
- 18-4 fetch로 GET 요청
  - fetch와 response.json으로 데이터를 받는다. 실습: JSONPlaceholder 글 목록을 화면에 그리기
- 18-5 실패 처리
  - response.ok 확인과 네트워크 오류를 구분해 처리한다.
- 연습문제
  - 사용자 목록 카드로 그리기
  - 잘못된 주소 요청 시 오류 메시지 표시

### 19장. JSONPlaceholder로 CRUD 통신
- 19-1 목록과 단건 조회
  - GET /posts와 /posts/1로 목록과 한 건을 받는다.
- 19-2 POST로 등록
  - method, headers, body를 붙여 보낸다.
- 19-3 PUT으로 수정
  - 한 건을 통째로 바꿔 보낸다.
- 19-4 DELETE로 삭제
  - 지우고 응답 상태를 확인한다.
- 19-5 로딩·오류 상태 표시
  - 요청 중과 실패를 화면에 보여 준다. 실습: 할 일 목록 등록·수정·삭제 통신
- 연습문제
  - 댓글 목록 조회와 등록
  - 사용자 정보 수정 폼

### 20장. [종합 프로젝트] 게시글 관리
- 사용하는 장: 8, 13~19장
- 예제: 원고에서 만듦
- 20-1 화면 배치
  - Grid로 게시글 카드 목록과 입력 영역을 배치한다.
- 20-2 목록 불러오기
  - fetch로 글을 받아 상태 배열에 넣고 그린다. 로딩을 표시한다.
- 20-3 등록·수정·삭제

  - 제목 검색과 작성자 필터 버튼으로 목록을 거른다.

  - 요청 실패를 잡아 메시지를 띄우고 화면이 깨지지 않게 한다.
