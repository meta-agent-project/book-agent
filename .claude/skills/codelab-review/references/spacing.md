# 띄어쓰기 검수 기준

한글 맞춤법의 띄어쓰기 규정 중 코딩 교재 원고에서 자주 틀리는 것만 모았다. 판단이 갈리면 표준국어대사전에 한 단어로 올라 있는지를 기준으로 한다. 확신이 없으면 고치지 말고 "판단 필요"로 보고한다.

## 검사하는 곳

- 본문 문장, 목록, 표의 한글 칸
- 코드 블록 안의 한국어 문자열과 주석(화면에 보이는 글자라서)
- 기본 문법의 한국어 자리표시도 본문과 같이 띄어 쓴다(`파일 경로`, `새 값`, `노드 또는 문자열`). 기본 문법은 실행하지 않는 형태 설명이므로 자리표시에 공백이 있어도 된다. `변수명`처럼 한 단어인 것은 붙여 쓴다

장 제목, 세부항목 제목, 연습문제 제목은 강의계획서와 같아야 하므로 고치지 않고 "계획서와 함께 고칠 것"으로 보고한다. 실행 결과와 에러 메시지 원문은 검사하지 않는다.

## 규칙

| ID | 규칙 | 틀린 예 | 맞는 예 |
|---|---|---|---|
| S-1 | 조사는 앞말에 붙인다. 인라인 코드, 영어, 숫자 뒤 조사도 붙인다 | `` `let` 과 ``, `HTML 에서` | `` `let`과 ``, `HTML에서` |
| S-2 | 의존명사는 띄운다: 것, 수, 때, 데, 만큼, 뿐, 줄, 바, 대로, 듯, 채, 지(경과) | `할수 있습니다`, `실행할때`, `바꾼것` | `할 수 있습니다`, `실행할 때`, `바꾼 것` |
| S-3 | 같은 글자가 체언 뒤에서 조사로 쓰이면 붙이고, 관형어 뒤에서 의존명사로 쓰이면 띄운다 | `값 만큼`, `배운대로` | `값만큼`(조사), `배운 대로`(의존명사) |
| S-4 | 보조용언은 이 원고에서 띄어 쓴다 | `보여줍니다`, `알아두세요`, `해봅니다` | `보여 줍니다`, `알아 두세요`, `해 봅니다` |
| S-5 | 수와 단위: 아라비아 숫자 뒤 단위명사는 붙인다. 순서를 나타내는 "-째", "번째"도 붙인다 | `2 칸`, `14 번째 줄` | `2칸`, `14번째 줄` |
| S-6 | 사전에 한 단어로 없는 명사 결합은 띄운다 | `파일경로`, `줄번호`, `새값`, `에러메시지` | `파일 경로`, `줄 번호`, `새 값`, `에러 메시지` |
| S-7 | 사전에 한 단어로 있는 말은 붙인다 | `새로 고침`, `내려 받기` | `새로고침`, `내려받기` |
| S-8 | 부정 부사 "안", "못"은 띄운다. 한 단어인 "안되다(불쌍하다)", "못하다(능력이 모자라다)", "못되다"는 붙인다 | `실행이 안됩니다`, `출력 못합니다`(불가능의 뜻) | `실행이 안 됩니다`, `출력하지 못합니다` |
| S-9 | "-하다", "-되다", "-시키다"가 붙는 동사는 붙인다 | `저장 합니다`, `연결 됩니다` | `저장합니다`, `연결됩니다` |
| S-10 | 접미사는 붙인다: -들, -씩, -쯤, -끼리. 관형사 "맨", "첫", "새"는 띄운다 | `한 줄 씩`, `사용자 들`, `맨앞` | `한 줄씩`, `사용자들`, `맨 앞` |
| S-11 | 문장부호 뒤는 한 칸, 앞은 붙인다. 괄호 안쪽은 붙인다 | `값 ,`, `( variable )` | `값,`, `(variable)` |
| S-12 | 연속 공백 | `값을  출력합니다` | `값을 출력합니다` |

## 일관성 검사

맞춤법상 둘 다 허용되는 말(보조용언 붙여쓰기 허용 등)은 원고 안에서 한 가지로 통일되어 있는지 본다. 장 안에서 같은 말이 두 가지로 쓰였으면 많이 쓴 쪽으로 맞추는 수정안을 낸다.

보고서에는 이렇게 묶어 쓴다.

```markdown
| 번호 | 원고 줄 | 규칙 | 현재 | 수정안 |
|---|---|---|---|---|
| 12 | 87, 143 | S-4 일관성 | 보여줍니다 (2회) / 보여 줍니다 (5회) | 보여 줍니다로 통일 |
```

## 자주 나오는 말

이 과정 원고에서 쓰는 표기다. 새로 정한 표기가 있으면 여기에 더한다.

| 쓰는 표기 | 쓰지 않는 표기 |
|---|---|
| 새로고침 | 새로 고침 |
| 개발자 도구 | 개발자도구 |
| 확장 프로그램 | 확장프로그램 |
| 에러 메시지 | 에러메시지 |
| 줄 번호 | 줄번호 |
| 파일명 | 파일 명 |
| 따라 쳐서 | 따라쳐서 |
| 알아 두세요 | 알아두세요 |
| 보여 줍니다 | 보여줍니다 |
| 알림창, 검색창, 주소창 | 알림 창, 검색 창, 주소 창 |
| 글자 색 | 글자색 |
| 기본 문법 자리표시도 띄어 씀: `파일 경로`, `새 값` | `파일경로`, `새값` |
